## Summary

This candy composes `pod-marimo`, which pinned `layer-cuda` at the pre-fix tag whose transitive `layer-nvidia` ref is the `#12` commit. `#12` removed the `stdout:` matcher so the Arch arm could skip honestly, and left the guard deciding whether to skip:

```
if [ ! -e /etc/dnf ] && [ ! -e /etc/yum.repos.d ]; then exit 0; fi
```

That skips only when **both** are absent, while the comment above it states the intent as *"no DNF at all"*. This pins that tag.
